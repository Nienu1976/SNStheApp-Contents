# 実装計画: Q1GrandPrixPack1 (q0121〜q0300) 音声再生成

Q1GrandPrixPack1の `q0121` 〜 `q0300`（全180問）の音声ファイルを、これまでのフィードバック（ポーズ時間、アクセント、ルビ読み分け、促音明瞭化、カギ括弧処理等）を網羅的に反映したパイプラインで一括再生成し、高品質なmp3ファイルを生成します。

---

## これまでの修正依頼に基づく改善ルール

1. **ポーズ・ブレスの厳格な標準化**:
   - 冒頭「問題」の直後のポーズ: **1.00秒** (`vowel_length = 1.00`)
   - 文中の読点「、」のブレス: **0.20秒** (`vowel_length = 0.20`)
   - カギ括弧「」の直前・直後の不自然なポーズの自動除去
2. **テキスト正規化 & ルビ（よみがな）反映**:
   - CSV内の `漢字 (よみがな)` / `漢字（よみがな）` を自然な読み仮名へ置換。
   - 人名や固有名詞中の中黒「・」（例: `こざき・ひろし`、`うちむら・てるよし`）はポーズを挟まず一語として発音。
   - `1つずつ`、`第48回` 等の数字・助数詞表記をOpenJTalkが誤読しないよう最適化。
3. **アクセント・イントネーションの最適化**:
   - 疑問文語尾（「何でしょう」「誰でしょう」「何というでしょう」等）のピッチが跳ね上がりすぎない自然なアクセント。
   - 頭高型・平板型などの自然な複合語アクセント適用。
4. **促音（っ）の明瞭化**:
   - 「とって」が「とおって」に長音化して聞こえないよう、促音の無音時間を確保し直前母音長を適切に制御。
