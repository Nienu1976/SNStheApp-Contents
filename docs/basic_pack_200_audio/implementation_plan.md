# BasicPack200 音声再生成 実装計画書

## 目的
`/Users/ishiiisamu/Documents/GitHub/SNStheApp-Contents/BasicPack200/Basicpack200.csv`（全200問）の音声ファイルを、最新のポーズルール・辞書登録ルールに基づき全問再作成する。

## ルールと方針
1. 『』内の固有名詞、および（）表記の読み仮名を事前調査し、VOICEVOX ユーザー辞書に登録する。
2. （）内を本文から除外し、二重発声を防止する。
3. ポーズ仕様:
   - 「問題。」直後: 1.00s
   - 「、」直後: 0.40s
   - 「『（開き括弧）直前: 0.20s
   - 」』（閉じ括弧）直後: 0.00s
   - 「・」（中黒）: 0.00s
   - 句末: 0.00s
4. 音量正規化: loudnorm=I=-16:TP=-1.5:LRA=11, 冒頭無音マージン: adelay=140|140
