## 2. 実施したルールと仕様

### ① 固有名詞・人名の精査とユーザー辞書登録
- 全200問の問題文・正解文を解析し、二重鉤括弧『』内の固有名詞、および人名（後ろに読み仮名があるもの）など **計72単語** を VOICEVOX ユーザー辞書（Port 50121）に登録・更新しました。
- 単語の例:
  - 『HUMBLE.（ハンブル）』 ➔ 読み `ハンブル`
  - 池田菊苗（いけだ・きくなえ） ➔ 読み `イケダキクナエ`
  - 日比野（ひびの）カフカ ➔ 読み `ヒビノカフカ`
  - 『葬送のフリーレン』 ➔ 読み `ソウソウノフリーレン`
  - 『一休さん』 ➔ 読み `イッキュウサン`
  - 『君の名は。』 ➔ 読み `キミノナワ`
  - 『走れメロス』 ➔ 読み `ハシレメロス` 等

### ② ルビ（読み仮名）の重複防止
- 本文中の `日比野（ひびの）カフカ` や `『HUMBLE.（ハンブル）』` といった表記について、読み仮名部分 `（...）` を音声合成テキストから除去し、辞書側で読みを強制適用することで「日比野ひびのカフカ」のような二重読み上げを防止しました。

### ③ ポーズ（間）と音響仕様
- **冒頭「問題。」直後**: **`1.00s`**
- **読点「、」直後**: **`0.40s`**
- **開き括弧「 / 『 の直前**: **`0.20s`**
- **閉じ括弧」 / 』 の直後**: **`0.00s`（間なし・シームレス直結）**
- **中黒「・」**: **`0.00s`（間なし）**
- **句末**: **`0.00s`（間なし）**
- **冒頭無音マージン**: `adelay=140|140`（約0.14秒の自然な立ち上がりマージン）
- **音量正規化**: EBU R128 (`loudnorm=I=-16:TP=-1.5:LRA=11`)
- **音質**: VOICEVOX Nemo 男声3 (`speaker: 10002`), 48kHz, 192kbps MP3
