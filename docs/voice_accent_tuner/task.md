# タスクリスト: 声でアクセント調整できる音声チューナーWebツール開発

## 目的
ユーザーがマイクに向かって発声するだけで、その声の高低（ピッチ・抑揚）を自動解析し、VOICEVOX Nemoの各モーラピッチ・アクセントに転写して一発で自然な問い読み音声を生成・保存できるローカルWebツールを構築する。

## タスク進捗
- [ ] **Phase 1: 設計とバックエンド音声解析エンジンの実装**
  - [ ] ピッチ抽出（YIN/F0解析）モジュールの実装
  - [ ] VOICEVOX Nemo API連携（クエリ取得・ピッチ転写・合成）
- [ ] **Phase 2: リッチなWeb UI（フロントエンド）の実装**
  - [ ] 問題選択（Pack1/Pack2、全問題リスト）
  - [ ] マイク録音機能（MediaRecorder API）
  - [ ] ピッチカーブ可視化・プレビュー試聴・保存機能
- [ ] **Phase 3: ローカルサーバー起動と動作検証**
  - [ ] ローカル起動（http://localhost:8888）
  - [ ] 実際の音声でのピッチ転写・上書きテスト
