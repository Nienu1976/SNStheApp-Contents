# 実装完了報告 (Walkthrough): 声でアクセント調整できる音声チューナーWebツール

## 開発概要
ユーザーがマイクに向かって声を発するだけで、そのピッチ（声の高低・抑揚）を自動抽出し、VOICEVOX Nemoの各モーラ音高に直接マッピングして、自然な問い読み音声を生成・試聴・上書き保存できるローカルWebツール **「Voice Accent Tuner」** を構築しました。

## アクセスURL
- **URL**: [http://localhost:8888](http://localhost:8888)

## 主な機能
1. **問題ブラウザ**: Pack1 / Pack2 の切り替え、全問題（q0001〜q0300）の選択・テキスト編集
2. **マイク録音・自動ピッチ解析**:
   - ブラウザからマイク録音（MediaRecorder）
   - バックエンド（YINピッチ抽出アルゴリズム）で基本周波数（F0）を解析し、VOICEVOXの各モーラに抑揚を自動転写
3. **モーラ別ピッチエディタ**:
   - 各音（モーラ）の高さが縦スライダーで視覚的に表示され、手動での微調整も可能
4. **プレビュー合成 & 一発上書き保存**:
   - 「▶️ VOICEVOXで試聴する」で即座に再生確認
   - 「💾 この問題のmp3に上書き保存」で EBU R128 (-16 LUFS) の音量均一化を自動適用して上書き保存
